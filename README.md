## Overview

Let Me Out is an immersive multiplayer escape room experience that challenges players to explore, solve puzzles, and work together against time. The game offers:

- **Adaptive Difficulty**: Choose between casual and challenging experiences
- **Performance Tracking**: Individual and team-based scoring system
- **Real-time Multiplayer**: Seamless communication and collaboration
- **Browser-based AAA Quality**: Premium gaming experience in your browser

## Development Journey

This project represents a passionate endeavor to push the boundaries of browser-based gaming. Inspired by acclaimed titles like Inscryption and Resident Evil, every aspect - from concept art to game mechanics - was crafted from scratch with dedication to quality and innovation.

The goal was to transcend typical browser game limitations and deliver an experience that rivals downloadable games, creating an environment where players forget they're playing in a browser.
